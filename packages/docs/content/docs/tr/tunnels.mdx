# Tüneller

Bir tünel, Magio'ınıza giden bir bağlantıdır. Böylece başka bir ağdaki normal bir tarayıcıdan ya da Tailscale Serve ile tailnet'inizdeki herhangi bir cihazdan erişebilirsiniz. Çalışan bir örnek için bir tane oluşturmak üzere `magio tunnel` kullanın.

> **Kendi cihazlarınızı** bağlamak, yani mobil uygulama ya da başka bir masaüstü, genelde tünel gerektirmez. Bunun yerine [eşleştirin](/connect-devices/) ve ev dışı erişimi sıfır kurulumla uçtan uca şifreli [Private Relay](/private-relay/) üzerinden bırakın.

## Ön koşullar

Magio, tünel sağlayıcısının CLI'sını sizin makinenizde başlatır. Önce kullanmak istediğiniz sağlayıcıyı kurun:

```bash
brew install cloudflared
brew install ngrok
```

Tailscale için [Tailscale uygulamasını](https://tailscale.com/download) kurun ve oturum açın. Mac'te uygulama yeterlidir: Magio komut satırı aracını uygulamanın içinde bulur.

Cloudflare quick tüneller `cloudflared` ile çalışabilir. Ngrok için bir ngrok hesabı ve ngrok panelinden alınmış bir authtoken gerekir:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Hızlı başlangıç

1. Magio'ı başlatın:

```bash
magio
```

Bu adımı atlarsanız `magio tunnel start` bir CLI sunucusunu otomatik başlatabilir. Otomatik başlatırken `--port`, `--host`, `--lan`, `--ui-password` ve `--api-only` gibi sunucu seçeneklerini verebilirsiniz.

2. Cloudflare tüneli başlatın:

```bash
magio tunnel start --provider cloudflare --mode quick
```

Ya da bir Ngrok tüneli başlatın:

```bash
magio tunnel start --provider ngrok --mode quick
```

Ya da Tailscale Serve ile tailnet'inizdeki cihazlarla paylaşın:

```bash
magio tunnel start --provider tailscale --mode serve
```

3. Durumu kontrol edin:

```bash
magio tunnel status
```

Tünel ayaktayken `status` bir genel URL gösterir. Onu açın ya da QR kodunu tarayın, Magio'a her yerden ulaşın.

Varsayılan olarak Magio, etkileşimli TTY oturumlarında bir QR kodu basar. QR çıktısını zorlamak için `--qr`, kapatmak için `--no-qr` kullanın.

## Sağlayıcılar

- `cloudflare`: quick, managed remote ve managed local modları
- `ngrok`: quick modu
- `tailscale`: yalnızca tailnet'inizdeki cihazlardan açılabilen serve modu ve tüm internetten açılabilen funnel modu

## Tailscale

İki mod da makinenizin `https://laptop.example.ts.net` gibi tailnet adresini kullanır. Portu `--https-port` ile seçin: 443 (varsayılan), 8443 veya 10000. Tailscale 443'te zaten başka bir şey paylaşıyorsa değiştirin.

İlk seferde Tailscale, tailnet'iniz için HTTPS'i (Serve için) veya Funnel'ı açmanızı ister. Magio durur ve Tailscale'in bağlantısını gösterir: açın, onaylayın ve tüneli yeniden başlatın. Linux'ta portları yalnızca root veya Tailscale operatörü paylaşabilir; kendinizi bir kez `sudo tailscale set --operator=$USER` ile operatör yapın.

Tüneli durdurmak Magio'ın Tailscale üzerinden paylaştığını kaldırır, Tailscale ayarlarınızın geri kalanına dokunmaz.

## Managed modlar

### Managed remote

Cloudflare tarafından yönetilen token + hostname kullanın:

```bash
magio tunnel start --provider cloudflare --mode managed-remote --token-file ~/.secrets/cf-token --hostname app.example.com
```

### Managed local

Yerel bir `cloudflared` yapılandırması kullanın:

```bash
magio tunnel start --provider cloudflare --mode managed-local --config ~/.cloudflared/config.yml
```

## Profiller (managed-remote)

Yeniden kullanılabilir bir profil kaydedin:

```bash
magio tunnel profile add --provider cloudflare --mode managed-remote --name prod-main --hostname app.example.com --token-file ~/.secrets/cf-token
```

Kaydedilmiş profili kullanarak başlatın:

```bash
magio tunnel start --profile prod-main
```

## Faydalı komutlar

```bash
magio tunnel providers
magio tunnel ready --provider cloudflare
magio tunnel ready --provider ngrok
magio tunnel doctor --provider cloudflare
magio tunnel doctor --provider ngrok
magio tunnel doctor --provider tailscale
magio tunnel stop --port 3000
```

## Davranış notları

- Magio örneği başına bir aktif tünel, yani port
- Aynı örnekte yeni bir mod ya da sağlayıcı başlatmak önceki tüneli değiştirir
- Yeni bir bağlantı bağlantısı oluşturmak, kullanılmamış önceki bağlantıyı iptal eder
- Tünel otomatik başlatma, `--ui-password` ve `--api-only` gibi sunucu bayraklarını yeniden başlatma/güncelleme akışlarında kullanılan örnek ayarlarında korur
