# Installeren

U kunt Magio op drie manieren gebruiken:

- als desktopapp voor macOS
- als webapp via de CLI, ook te installeren als app op uw telefoon via een PWA
- als VS Code-extensie

## Vooraf

Installeer eerst [OpenCode](https://opencode.ai). Magio bouwt daarop voort.

## Web en PWA

```bash
curl -fsSL https://raw.githubusercontent.com/gitcoffee-os/magio/main/scripts/install.sh | bash
magio --ui-password be-creative-here
```

Open de URL die de CLI toont, meestal `http://localhost:3000`. U ziet nu de sessielijst van Magio. Via de optie 'Installeren' in de adresbalk van uw browser kunt u de webapp als app toevoegen.

## Desktop

Download de nieuwste desktopversie via de GitHub-releases of de downloadpagina van Magio. Open de app en meld u aan zoals u gewend bent voor OpenCode.

## VS Code

Installeer de extensie via de VS Code Marketplace en meld u aan zoals u gewend bent voor OpenCode. De Magio-weergave verschijnt vervolgens in de zijbalk.
